Small, boring, done

Oct 23, 2026

The temptation with any new tool is to build the cathedral. A dashboard for everything. A system to rule the systems.

The things that actually stuck were small. One job each. Clear inputs, clear outputs, a check at the end that tells me if it worked. They’re boring to describe, which is the point — boring means reliable, and reliable means I stop thinking about it.

This website is the same idea. Plain HTML. One stylesheet. No framework to update, no plugin to patch. It will still load in ten years. That’s the feature.

small  > clever
boring > novel
done   > perfect
